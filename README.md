# البصمة البيئية – Empreinte écologique (Lycée Oued Ellil)

Application web du projet « البصمة البيئية » : mesurer et réduire l'empreinte écologique du lycée.
Responsable du projet : Mme Sonia Aouichi (professeure d'anglais).

## Pages
- `index.html` : présentation, objectifs, accès aux outils
- `calculateur.html` : calcul de l'empreinte personnelle (transport, énergie, eau, papier, déchets, alimentation)
- `suivi.html` : suivi mensuel des consommations du lycée et bilan
- `sensibilisation.html` : écogestes, glossaire FR/AR/EN, quiz, boîte à idées

## Conformité
HTML5, CSS3 et JavaScript limités aux éléments de l'annexe officielle STI (niveau Bac) : JavaScript externe, sans `addEventListener`, `querySelector`, `toFixed`, flexbox, grid ni media queries.
Site statique, sans PHP : publiable tel quel sur GitHub Pages.

## Limites
- Facteurs d'émission : électricité, voiture, moto, bus sourcés ; eau, papier, déchets, alimentation = valeurs pédagogiques indicatives à valider avec l'enseignant scientifique.
- Les données saisies ne sont pas enregistrées.
