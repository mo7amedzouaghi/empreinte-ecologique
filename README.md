# البصمة البيئية – Empreinte écologique · Ecological footprint

Application web du projet « البصمة البيئية » du Lycée Oued Ellil.
Responsable du projet : Mme Sonia Aouichi (professeure d'anglais).

Site statique (HTML, CSS, JavaScript), sans dépendance ni serveur : il suffit d'ouvrir `index.html` ou de publier sur GitHub Pages.

## Fonctionnalités
- Interface en **français, arabe (écriture de droite à gauche) et anglais**
- **Calculateur** d'empreinte personnelle en direct, graphique en anneau, niveau d'impact, équivalent en arbres, historique, impression du rapport
- **Suivi du lycée** : saisie mensuelle (électricité, eau, papier), graphique avec objectif −10 %, export et import CSV
- **Défis** écologiques avec points et badges
- **Quiz** de 6 questions avec explications
- **Glossaire** FR / AR / EN avec recherche
- Thème clair / sombre, adapté aux téléphones, accessible au clavier
- Données sauvegardées dans le navigateur (localStorage)

## Facteurs d'émission (kg CO2e)
Électricité 0,47/kWh (réseau tunisien, IEA) · voiture 0,218/km · moto 0,113/km · bus 0,146/km (ADEME).
Eau, papier, déchets, alimentation : valeurs pédagogiques indicatives, à valider avec l'enseignant scientifique.
